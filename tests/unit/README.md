# tests/unit

Vitest unit tests for the engine.

- `expr.test.ts`, `units.test.ts`: the expression parser and unit handling.
- `pack.test.ts`, `rng.test.ts`: content-pack validation and seeded randomness.
- `judge.test.ts`, `learner.test.ts`: grading and the learner model.
- `log.test.ts`: event log.
- `libro.test.ts`: checks the solid-shaft results against the textbook's worked problems.
- `consecuencia.test.ts`: checks the visual consequence of the solid-shaft formulas.
- `helpers.ts`: shared test helpers.
