# tests/e2e

Playwright end-to-end specs for the game.

- `smoke.spec.ts`: the app loads without console errors.
- `a-world.spec.ts`, `b-platforms.spec.ts`: movement and platforms.
- `c-eje-macizo.spec.ts`: the solid-shaft exercise.
- `helpers.ts`: shared helpers; `screens/` receives screenshots from the runs.
